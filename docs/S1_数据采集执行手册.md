# S1 数据采集执行手册

> 适用阶段：S1-01 — S1-10　｜　目标：产出 1200 张带标注的训练图像
> 使用方法：进场前通读一遍，照表格逐项填写，标注阶段对照「标注规范」执行

---

## 一、S1-01 实地踏勘（约 40 分钟）

**携带**：手机、卷尺（或手机测距 App）、本手册、充电宝

### 必记 8 项

| # | 记录项 | 为什么必须记 | 填写 |
|---|---|---|---|
| 1 | 教室长 × 宽（米） | 决定机位距离与镜头焦距 | |
| 2 | 座位行列数、前后间距、左右间距 | 决定 ROI 划分与「一个座位」的边界 | |
| 3 | 桌子类型（单人桌 / 双人桌 / 连排桌） | 双人桌要按“两个座位”划 ROI | |
| 4 | 窗户位置与朝向 | 判断是否逆光；逆光会让桌面物品变成剪影 | |
| 5 | 灯具类型与数量（是否频闪） | LED 频闪会让相邻帧明暗跳变，影响标注一致性 | |
| 6 | 3 个候选机位（后墙中央、左后角、右后角） | 每个位置**拍一张“从该点看全场”的照片** | |
| 7 | 电源插座位置、Wi-Fi 信号强度 | 决定能否长期部署摄像头 | |
| 8 | 人流高峰时段（问管理员或看课表） | 决定采集时段，满座场景是核心样本 | |

### 机位判断标准（关键）

**推荐：后墙中央，高度 2.5—3 m，俯角 25—35°**

| 角度方案 | 优点 | 致命缺点 | 结论 |
|---|---|---|---|
| 后墙中央高角度俯拍 | 能看清桌面上的书、杯、背包 | 需要梯子或踩桌椅 | ✅ **首选** |
| 侧墙平视（与人眼齐平） | 架设容易 | 前排人/椅背**完全遮挡**后排桌面 | ❌ 弃用 |
| 天花板角落（吸顶） | 覆盖广 | 距离太远，小目标（水杯）只有几个像素 | ⚠️ 仅当无其他选择 |

**安全提醒**：登高架设需两人配合，一人扶梯一人操作，勿单人踩桌上举手机。

## 二、S1-02 座位编号规则

**统一规则，不要中途改**（改了标注全废）：

1. **方向基准**：以摄像头视角为准——**离镜头最近的一排为 A 排**，向里依次 B、C、D
2. **列号**：从画面左到右依次 01、02、03
3. **编号格式**：`行字母 + 两位列号`，如 `A01`、`C03`
4. **12 个试点座位**：选画面**中央区域 4 行 × 3 列**，避开画面四边（边缘有镜头畸变，桌椅会变形）

```
        画面左 ──────────── 画面右
近  A排  A01   A02   A03
    B排  B01   B02   B03
    C排  C01   C02   C03
远  D排  D01   D02   D03
```

在 `output/座位编号表.xlsx` 中登记每个座位的属性（靠窗 / 有插座 / 双人桌），
后续 ROI 标定和看板显示都依赖这张表。

## 三、S1-03 拍摄方案

### 3.1 核心方法：录视频 → 抽帧，不要一张张拍

| 方式 | 3 分钟能出多少张 | 人员操作 | 多样性 |
|---|---|---|---|
| 手机连拍 | 约 30 张（手会抖，机位会变） | 全程举着 | 差，画面几乎雷同 |
| **固定机位录像 + 抽帧** | **36 张（5 秒间隔）** | 架好后去自习 | 好，自带人员走动与物品变化 |

**结论：手机固定架好，录 15 分钟视频，回去用脚本抽帧。** 机位固定也保证了同一座位的像素位置稳定，ROI 才有意义。

### 3.2 采集量换算（目标 1200 张）

| 参数 | 数值 |
|---|---|
| 单段录像时长 | 15 分钟 |
| 抽帧间隔 | 5 秒 |
| 单段可出帧数 | 180 张 |
| 需要采集段数 | **12 段**（4 天 × 每天 3 个时段） |
| 抽帧总量 | 约 2160 张 |
| 去重筛选后保留 | **1200 张** |

### 3.3 时段与场景配额

| 时段 | 时间 | 主要场景 | 目标占比 |
|---|---|---|---|
| 上午 | 09:00—09:20 | 中等上座率 | 25% |
| 下午 | 14:00—14:20 | 高峰满座 | 40% |
| 晚上 | 19:00—19:20 | 夜间灯光 + 遗留物品（占座高发） | 35% |

**必须覆盖的三种极端场景**（各至少 100 张）：
1. **满座**：几乎无空位，人挨人，检测易漏框
2. **整排空置**：桌椅无人无物，用于学习“空”的特征
3. **夜间低照度**：仅靠顶灯，桌面偏暗

### 3.4 文件命名（必须统一）

```
20261104_0900_cam1_f0001.jpg
└─日期─┘ └时段┘ └机位┘ └帧号┘
```

抽帧脚本会按此规则自动命名，**不要手动改名**。

### 3.5 抽帧命令（录像拷回电脑后执行）

```bash
conda activate seat
cd /d D:\seat-project

python scripts\extract_frames.py --video "D:\videos\20261104_0900_cam1.mp4" --out data\raw --date 20261104 --slot 0900 --cam cam1 --every 5
```

参数说明：
- `--every 5`：每 5 秒抽一帧（人多走动频繁时可改 3，场景静态可改 10）
- `--out`：输出目录，统一 `data\raw`
- 执行完会打印「总帧数 / 抽帧数 / 输出路径」

## 四、隐私与合规（答辩会被问）

1. **只拍座位区域**，镜头避免对准人脸特写；机位取俯拍天然避开正脸
2. 原始图像**仅存本地**，不上传 GitHub（`.gitignore` 已排除 `data/`）
3. 答辩 PPT 与报告中的图像，**人脸需打码**或只展示标注框、不展示原图
4. 教室内拍摄前告知管理员用途，不拍摄与项目无关的内容

## 五、标注疑问清单（S1-05 用，边标边补）

| # | 疑问 | 定论 |
|---|---|---|
| 1 | 一摞 3 本书，算 1 个框还是 3 个框？ | 待定（建议：算 1 个框，取整摞外接矩形） |
| 2 | 背包挂在椅背上、人不在，算 bag 还是算「占座证据」？ | 待定（建议：标 bag，业务层再判定占座） |
| 3 | 衣服搭在椅背上，算 bag 吗？ | 待定（建议：**不算**，衣服不属于可识别物品） |
| 4 | 水杯被书挡住一半，还标吗？ | 待定（建议：可见面积 > 30% 就标） |
| 5 | 两个人挤一个座位，人框重叠怎么标？ | 待定（建议：各标各的，允许框重叠） |
| 6 | 桌上只有一支笔/一张纸，算「有物」吗？ | 待定（建议：**不算**，物体需满足最小面积阈值） |

> 四类类别固定为：**person / book / bag / cup**。不要自行增加类别。

## 六、常见卡点与对策

| 卡点 | 对策 |
|---|---|
| 借不到教室 / 管理员不允许 | 改用宿舍或空教室摆 4 行 × 3 列桌椅，报告里如实说明局限 |
| 手机架不到 2.5 m 高 | 降到 2 m + 后移，保证俯角 ≥ 20°；宁可远一点也不要侧拍 |
| 视频太大拷不出来 | 手机设置里降到 1080p / 30fps，15 分钟约 1 GB |
| 灯下画面频闪 | 抽帧间隔取 0.1 秒的整数倍，或后期调 `--every` 避开相邻暗帧 |
| 抽出的帧大量雷同 | 脚本内置相似度过滤（默认开启），自动丢弃与上一张差异过小的帧 |
