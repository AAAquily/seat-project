# 在其他设备上打开网页版（手机 / 平板 / 另一台电脑）

服务本身跑在你这台台式/笔记本上（推理要用本机 CPU 和模型），其他设备通过网络访问它。
下面两种方式**任选一种**，都用现成脚本，不需要改代码。

---

## 方式一：局域网访问（同一 Wi-Fi，最快、不依赖外网）

适用：手机和电脑连的是同一个路由器 / 同一个 Wi-Fi。

1. 双击 **`open_firewall_8000.bat`**
   - 会弹出「用户账户控制」窗口，点 **是**（这是放行防火墙端口，只需做一次）
   - 看到「已允许入站 TCP 8000」即成功
2. 双击 **`start_server.bat`**
   - 窗口里会显示两行地址：
     - `本机访问：http://127.0.0.1:8000/`
     - `其他设备：http://10.65.50.147:8000/`  ← 手机要输的就是这个
   - **这个窗口不要关**，关掉服务就停了
3. 手机连同一个 Wi-Fi，浏览器输入上面「其他设备」的地址

> IP 每次连网可能变，以窗口里显示的为准。

---

## 方式二：公网链接（不同网络也能开，含手机流量）

适用：手机不在同一 Wi-Fi、或者学校/公司网络禁止设备互访。

1. 先按方式一第 2 步，用 `start_server.bat` 把服务跑起来（窗口别关）
2. 再双击 **`start_public_tunnel.bat`**
   - 等 10~20 秒，窗口里会打印一行 `https://xxxx.free.pinggy.net`
   - 下面还有一个二维码，**手机直接扫**即可
3. 把这个链接发给任何人，都能打开

注意事项：

- 免费通道**约 60 分钟过期**，过期后重新双击 `start_public_tunnel.bat` 换一条新链接
- 链接是公开的：知道地址的人都能上传图片触发检测，**用完请按 Ctrl+C 关闭那个窗口**
- 主脚本窗口（`start_server.bat`）必须一直开着，关掉它就断
- 电脑休眠/断网会中断，回来重新双击两个 bat 即可

---

## 常见问题

**手机打开显示「无法访问此网站」**

1. 确认手机和电脑连的是**同一个** Wi-Fi（不要一个 Wi-Fi 一个流量）
2. 确认 `start_server.bat` 窗口还开着，且显示的是 `其他设备：http://...`
3. 防火墙没放行 → 重跑 `open_firewall_8000.bat`（要看到「已允许入站」）
4. 仍然不行，多半是**网络隔离**（校园网、酒店 Wi-Fi、公司网络常禁止设备互访）。
   这时直接用**方式二**的公网链接，或让手机开热点、电脑连热点后再用方式一

**提示端口已被占用**

说明服务已经在跑了。直接浏览器打开 `http://127.0.0.1:8000/` 试试；
要重启就先双击 `stop_server.bat`，再双击 `start_server.bat`。

**想让链接长期固定、不用每次换**

需要固定域名 + 稳定带宽，属于付费服务（pinggy Pro / Cloudflare 命名隧道）。
当前免费方案适合临时演示和上课展示。

**换了端口怎么办**

先 `set SEAT_PORT=8011` 再双击 bat；防火墙和公网脚本都要带上同一个端口
（`open_firewall_8000.bat 8011`、`start_public_tunnel.bat` 会自动读 `SEAT_PORT`）。

## 涉及的脚本

| 文件 | 作用 |
|---|---|
| `start_server.bat` | 启动服务，默认监听 `0.0.0.0`（局域网可访问），自动打印局域网地址 |
| `open_firewall_8000.bat` | 放行 TCP 8000 入站（自动提权，只需一次） |
| `start_public_tunnel.bat` | 把本机服务映射成公网 https 链接并显示二维码 |
| `scripts/share_public.py` | 隧道逻辑本身（需要时可直接命令行运行） |
| `stop_server.bat` | 停止占用端口的服务 |

默认监听地址可用环境变量覆盖：

```bat
set SEAT_HOST=127.0.0.1   &:: 只允许本机访问（更安全）
set SEAT_HOST=0.0.0.0     &:: 允许局域网访问（默认）
```
