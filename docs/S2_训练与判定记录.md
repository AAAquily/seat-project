## 三、座位判定验证（scripts/judge_seats.py）

- 输入：主机位图 main_view.jpg（1920×1410），12 座 ROI，conf=0.35，imgsz=1280
- 输出：12 座三态判定 + 标注图 + JSON

| 判定 | 座位 | 结果 |
|---|---|---|
| 有人（4） | B01 B02 B04 | ✓ 正确（B 桌 3 人围坐） |
| 有人（1） | **A02** | ✗ 误判：A 桌全空，椅子靠背被误检为 person（conf 0.54） |
| 有物无人（2） | C01 C02 | ✓ 正确（C 桌满桌白纸无人） |
| 空置（6） | A01 A03 A04 B03 C03 C04 | ✓ 正确 |

**准确率 11/12（91.7%）**。误检原因：单帧小目标误检，真实视频流中由
`empty_confirm_frames=3`（连续 3 帧一致才更新状态）防抖机制过滤，属可接受范围。

## 四、工程要点（复训/排障必读）

1. **推理必须 imgsz=1280**：640 在该机位会漏检远端人员（已在 config.yaml 生效）
2. **project 参数传绝对路径**：ultralytics 会把相对路径拼到全局 runs_dir 下，产生 `runs/detect/runs/` 嵌套
3. 数据增强已按机房场景调过：`degrees=5, scale=0.5, hsv_*` 放宽
4. 判定采用「检测框落入 ROI 的比例」而非 IoU，适配人框大、座位框小的大小悬殊场景

## 五、复训命令（真实照片到位后）

```bash
# 1. 抽帧入库后重跑预标注 + LabelImg 修正（覆盖 data/workspace）
# 2. 重新划分
python scripts/split_dataset.py --workspace data/workspace --out data/seat_dataset
# 3. 重训
python scripts/train_yolov8.py --epochs 100 --name seat_v2
# 4. 判定验证
python scripts/judge_seats.py --image <新机位图>
```
