# 手动标注重训记录（seat_v9 / v9b + 双模型融合）

> 目的：把「人工逐座框选 → 训练 → 评估 → 上线」这条链路完整跑一遍，并记录
> 每个版本的实测数据，避免再凭感觉换权重。
>
> 环境：本机 CPU（AMD Ryzen AI 7 H 450），`D:\miniconda3\envs\seat\python.exe`，
> ultralytics 8.4.190 / torch 2.14.1+cpu。

## 一、标注来源与校验

| 项 | 内容 |
|---|---|
| 标注工具 | LabelImg（YOLO 格式），`start_labelimg.bat` |
| 工作区 | `data/workspace/images`（28 张）+ `data/workspace/labels` |
| 类别 | person / book / bag / cup / item / **stool**（6 类，第 6 类为本轮新增） |
| 校验结果 | 28 个标签文件、1254 个框，坐标/类别/列数全部合法 |

本轮标注相对旧标签的三处关键改进：

1. **红脚凳从 item 重新归为 stool**，共 66 个框——旧数据几乎没教过 stool 类，
   导致 v6 完全认不出空红凳，座位实体存在性判断只能靠 HSV 红色兜底。
2. **紧邻两人各框各的**：real_01 左墙、real_09 左前景两人此前在旧标签里被合并成
   一个大框，是 v6「双人融框」误判的训练数据根源。
3. **删除 2 处海报证件照上的 person 误标**（real_08、real_09），避免把
   「海报人像 = 真人」教给模型。

## 二、两个版本的数据集差异

| 版本 | 训练集构成 | 说明 |
|---|---|---|
| seat_v9 | 19 张基础图 + 增广 → 99 张 | 按 7:1.5:1.5 随机切分，**9 张真实图里有 2 张被切进 test** |
| seat_v9b | 28 张基础图 + 增广 → 140 张 | 9 个固定机位全部进训练集（与 v8 做法一致） |

这是两个版本表现差距的主因：固定机位系统里，机位本身就是「类别」，
任何一张真实机位图缺席训练集，模型在该机位的表现就会掉一个档。

增广脚本 `build_dataset_v8.py` 新增 `--src/--dst`，支持多版本并存不覆盖：
全图 + 2×2 瓦片 + 海报负样本 + 纯背景负样本。

## 五、为配合新模型修的三处判定逻辑

1. **`classes.object_ids` 生效**：此前配置里写了 `object_ids: [1,2,3,4]` 但代码从未使用，
   stool 被当「物品」计数。v9b 的 stool 召回达 0.995，若不修，所有空红凳座位都会
   被误判成「有物无人」。
2. **海报过滤不再误杀座位上的真人**：`filter_tiny_persons` 会把「画面上部 + 矮 +
   conf<0.60」的人框当海报人像丢弃，但标定机位是近景构图（real_04 的 B05 座位
   y=39% 画面高），真人被误杀。新增 `seat_rois` 参数：人框中心落在任一标定座位内
   一律保留。这一处修完 real_04 直接全对。
3. **`cross_dedup` 未初始化 bug**：该阈值原先只在「中心点兜底」分支内赋值，
   一旦某张图没有任何框走兜底（v9/v9b 常见），后面的「溢出回填」就会
   `UnboundLocalError` 崩掉（real_02/real_03 实测崩溃）。已提到函数开头初始化。

## 六、上线配置

```yaml
model:
  weights: runs/train/seat_v8/weights/best.pt        # 动态通道不变
  fixed_weights: runs/train/seat_v6/weights/best.pt  # 标定通道主权重
  calib_ensemble:                                    # 标定通道追加权重（并集去重）
    - runs/train/seat_v6/weights/best.pt
    - runs/train/seat_v9b/weights/best.pt
```

- real_09 条目的 `weights: v8` 覆盖已移除（v9b 自己就能把左前景两人分开，
  融合后仍然全对），少跑一个模型。
- 网页上传接口（`app/main.py` + `app/detector.py`）同步支持权重列表，
  实测与 CLI 结果一致（real_08：4 有人 / 1 有物 / 5 空置）。
- 28 张动态通道回归：**27/28 = 96.4%，MAE 1.79**（与换模型前完全一致，未受影响）；
  状态机单测 13/13 通过。

## 七、剩余 4 座残差（模型能力/标注口径边界）

| 残差 | 原因 | 说明 |
|---|---|---|
| real_01 R05 | 两个模型都以 0.90 检出包，人工标注判空置 | 标注口径分歧，需人工复核该座 |
| real_02 R09 | 物品被桌面完全遮挡 | 画面无证据，任何模型都检不出 |
| real_08 D05/D06 | 挂在椅背的黑蓝包/白外套 | v6 只有 0.05~0.07，v9b 把整张红凳识别为 stool（0.90），包本身无响应 |

要进一步压缩残差，方向是**补「椅上挂物」正样本**（建议 ≥30 张特写，含夜间），
而不是继续调判定阈值——再降阈值会在空座区引入成片误检。
