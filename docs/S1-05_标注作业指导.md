# S1-05 标注作业指导

> 目标：把预标注初稿修正为可训练的 YOLO 标签。当前批次 19 张（网络素材），预标注 340 框。
> 原则：预标注只当起点，**每张图必须人工过一遍**。

---

## 一、类别定义（五类）

| 索引 | 类别 | 标什么 | 不标什么 |
|---|---|---|---|
| 0 | person | 坐着、站着、趴着、走路的人，可见头部或肩部即可 | 倒影、海报人像 |
| 1 | book | 书、笔记本、成摞的书（整摞一个框） | 散落的单张纸、报纸（存疑时宁可不标） |
| 2 | bag | 背包、手提包、行李袋（含挂椅背上的） | 塑料袋、衣物 |
| 3 | cup | 水杯、保温杯、饮料瓶 | 笔、纸巾等小杂物 |
| 4 | **item** | **书 / 包 / 杯以外的占座物品**：笔记本电脑、平板、雨伞、外套、快递盒、抱枕、饭盒 | 已能归入前四类的东西（**不要重复标**）、笔和纸等小件 |

**item 类的用途**：覆盖「桌上放着东西但不是书也不是包」的占座方式，例如摊开的笔记本电脑、搭在椅背的雨伞、一摞快递盒。判定模块把 book / bag / cup / item 任一命中都算「有物」，所以标哪一类不影响到三分类结论，但影响模型学到什么形状。

**归类优先级**：能归到 book / bag / cup 的一律归前三类，都不像才用 item。一个物体只标一次。

手册六个疑问的定论（沿用建议，标注时直接执行）：

1. 一摞书 → **1 个框**（取整摞外接矩形）
2. 椅背挂包、人不在 → **标 bag**（占座判定交给业务层）
3. 衣服搭椅背 → **不标**
4. 水杯被挡一半 → 可见面积 **> 30% 就标**
5. 两人挤一座 → **各标各的**，允许框重叠
6. 只有一支笔/一张纸 → **不标**（太小且无判座价值）

## 二、本次要修正的三类问题（按优先级）

1. **补 bag / cup**（最缺）：train 集里 bag 只有 2 个框、cup 11 个。
   桌上每个背包、每个水杯都要有框——这是「有物无人」判定的直接证据。
2. **补漏检的 person**：趴在桌上的人（COCO 常漏）、远景小人。
3. **删误检框**：套在白纸上的 book 框、套在椅背上的奇怪框。

## 三、LabelImg 操作流程

启动：双击项目根目录的 `start_labelimg.bat`

1. 左侧格式按钮切到 **YOLO**（默认可能是 PascalVOC，必须切换）
2. 快捷键：`W` 画框 → 选类别；`D` 下一张 / `A` 上一张；`Del` 删框；`Ctrl+S` 保存
3. 每张改完 **必须 Ctrl+S**（底部会闪保存提示），标签存到 `data\workspace\labels`
4. 19 张全部过完后告诉我，我跑划分校验 + 训练前的完整性检查

## 四、质量抽查规则

- 每标完 5 张喊我一次，我抽 1 张把标签画回原图核对（框偏移、类别错、漏标）
- 全部完成后我跑三项自动检查：坐标越界、类别索引合法、空标签文件
