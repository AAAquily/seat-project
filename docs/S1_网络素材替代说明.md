# S1 数据采集 · 网络素材替代方案说明

> 状态：S1 实地拍摄暂缓，改用网络自习室图片先跑通全链路；真实素材到位后仅替换数据，代码与配置流程不变。

---

## 一、替代方案的范围与局限

| 项目 | 说明 |
|---|---|
| 覆盖的环节 | 素材归档、ROI 标定、模型推理验证、三分类状态核对 |
| 不覆盖的环节 | 防抖（需连续帧）、占座时长累计（需时间序列）、模型再训练（需同场景标注数据） |
| 主要局限 | 网络图来自不同场景、无固定机位时间序列，只能验证工程正确性，不能产出最终模型 |

## 二、素材情况

- 来源：网络搜集真实自习室 / 图书馆照片，共 **19 张**（原始文件存于 `D:\image`，未改动）
- 归档：统一转为 JPEG 并按 `20261104_0900_web_f0001.jpg` 规范命名，存入 `data/raw/`
- 溯源：`data/raw/web_images_manifest.csv` 记录「新文件名 ↔ 原文件名」对照
- 主机位图：`20261104_0900_web_f0010.jpg`（图书馆中庭高机位俯拍，1920 × 1410）

## 三、ROI 标定结果（config/rois.json）

- 试点 12 座 = 中央 3 张方桌 × 每桌 4 座，编号 A01—C04
- 三种状态天然齐全：A 桌全空置、B 桌有人、C 桌满桌纸张无人（典型占座）
- 标定与微调工具：`scripts/roi_tool.py`（交互拖框 / 自动网格 / 读入续编 / 预览四种模式）
- 预览核对图：`data/video_demo/roi_preview.jpg`

## 四、基线推理验证（2026-11-04）

用预训练 yolov8n.pt 在主机位图上推理（conf=0.15，imgsz=1280，CPU）：

| 类别 | 检出数 | 说明 |
|---|---|---|
| chair | 99 | COCO 有椅子类，可作为座位辅助参照 |
| person | 37 | 与图中实际人数量级一致 |
| laptop / book / backpack / handbag | 16 / 1 / 4 / 1 | 「有物无人」判定的物品证据可直接复用 COCO 类别 |

结论：预训练模型在该类俯拍场景下人、椅、物品均能检出，**训练前即可用「COCO 预训练 + ROI 判定」先跑通业务逻辑**；后续用标注数据再训练以提升精度。

⚠️ 注意：正式推理时 `imgsz` 需设为 1280（config.yaml 当前为 640，远距离小目标会漏检）。

## 五、真实素材到位后的衔接步骤

1. 按原计划完成踏勘与固定机位录像（S1 执行手册不变）
2. `extract_frames.py` 抽帧 → 覆盖 `data/raw/`
3. `roi_tool.py` 在新机位图上重新标定 → 覆盖 `config/rois.json`
4. LabelImg 标注 → 训练 → 把 config.yaml 的 weights 指向新权重
