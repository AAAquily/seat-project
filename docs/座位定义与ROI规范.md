# 座位定义与 ROI 规范（v2）

> 2026-11-05 与项目负责人确认的口径，替代早期"桌面四等分"的临时模型。

## 一、座位定义

1. **一个座位 = 一把椅子 + 椅子正前方一定范围的桌面**；
2. 一张大桌子旁有 N 把椅子，就有 **N 个座位**（座位数 = 贴桌椅子数）；
3. 判定时在座位区域内统计 person / 物品框，任一物品命中即"有物无人"，person 命中即"有人"。

## 二、数据模型（config/rois.json）

```json
{
  "seat_model": "chair+desk",
  "seats": [
    {
      "id": "B01",                // 座位编号
      "name": "B桌1号",
      "side": "top",              // 椅子所在边：top远边 / bottom近边 / left左端 / right右端
      "chair": [x1, y1, x2, y2],  // 椅子区（画面坐标）
      "desk":  [x1, y1, x2, y2],  // 椅前桌面条带
      "roi":   [x1, y1, x2, y2]   // 判定区域 = chair ∪ desk（外接矩形）
    }
  ]
}
```

`config.yaml` 的 `seats:` 段由 `make_web_rois.py --sync-config` 自动生成，勿手工编辑。

## 三、生成与标定流程

```bash
# 1. 在叠加坐标网格的放大图上人工读出：桌面矩形 + 每把椅子的边与沿边位置
#    （参考 data/video_demo/desk_*_grid.jpg 的做法）
# 2. 把桌子登记进 scripts/make_web_rois.py 的 DESKS 表
python scripts/make_web_rois.py --sync-config   # 生成 rois.json + 预览图 + 覆盖 config.yaml
# 3. 渲染核对
python scripts/judge_seats.py --image <底图>     # 判定结果应与画面事实一致
# 4. 微调仍可手改 rois.json 后用 roi_tool.py 拖框精修
```

几何参数在 `make_web_rois.py` 的 `SIDE_PARAMS`：椅子区与桌面条带的深度按桌子尺寸比例伸缩
（近边椅子在画面里更大；bottom 带深压到椅子实际高度，防止画面更近处的人被算进来）。

## 四、判定规则（scripts/judge_seats.py）

| 规则 | 参数（config.yaml） | 说明 |
|---|---|---|
| 人物归属 | `person_iou_threshold: 0.50` | 人体框主体落在座位 ROI 内；取高值防止**邻桌的人**被算进来 |
| 物品归属 | `object_iou_threshold: 0.10` + `min_object_area_ratio: 0.02` | 物品框落入 ROI 且有最小面积，过滤远端噪点 |
| 独占分配 | — | 每个检测框只归属重叠比例最大的座位，相邻座位不重复计数 |
| 同人去重 | — | 同一座位内两个 person 框交集占较小框 >50% 视为同一人（NMS 漏检兜底） |

### 7.2 座位双区模型（object_roi）

一个座位 = 椅子区（`roi`，判人）+ 椅前桌面物品区（`object_roi`，可选，判物）：

```yaml
seats:
  - id: V01
    name: 单座测试
    roi: [0, 300, 480, 1010]        # person 框只按它判定
    object_roi: [300, 330, 540, 495] # 配置后物品框只按它判定（书 x310-460、水瓶 x475-525、y340-485）
```

动机：演示视频里桌面左侧有纸巾盒、路由器等**长期固定物**（x<300），若与用户遗留物品共用一个矩形，
空座会被永久误判为「有物无人」。配置 `object_roi` 把固定物圈在物品区外即可。
未配置 `object_roi` 的座位行为与旧版完全一致（人和物都按 `roi` 判定）。

> 标注教训：在小图上读网格坐标会有系统性偏移，定位小目标（书/水瓶）务必用
> 「原分辨率局部裁剪 + 50px 网格放大」复核，并用标注回显图逐框核对。

### 7.3 视频通道独立座位表（config.yaml → video_seats）

上传视频识别（看板「视频」标签）使用 `video_seats`（适用竖屏单座测试视频 720×1280）；
留空则回退 `seats`。修改 `app/video_job.py` 与 `scripts/judge_seats.py` 支持。

### 7.4 单座视频三态实测

视频 39.6s、720×1280、固定机位，真实时间线：

| 时段 | 画面 | 预期判定 |
|---|---|---|
| 0–8s | 空椅，桌上只有纸巾盒/插排等固定物 | 空置（固定物被 object_roi 排除）|
| 8–15s | 人坐下写字，翻开的书+水瓶上桌 | 有人 |
| 16–27s | 人起身走开，**桌上留书+水瓶** | 有物无人（占座信号）|
| 28–32s | 人回来坐下（31s 起身收拾） | 有人 |
| 33s–结尾 | 人带走书和水瓶离开 | 空置 |

判定经验：人站立在椅子附近但未离开画面时，只要人体框落入 `roi` 就判「有人」，属正常行为；
「有物无人」只在人离开 `roi` 且物品仍在 `object_roi` 内时出现。


## 八、人数优先判定与实体座位（2026-11-06 更新）

### 8.1 漏检原因分析（real_03 六人只检出五人）

| 漏检对象 | 直接原因 | 根因 |
|---|---|---|
| 窗边白衣女 | 已检出（conf 0.58），但人框与座位 ROI 重叠率仅 0.05 < 0.50，被归属逻辑丢弃 | 座位 ROI 按底图标定，视角变化后人在 ROI 之外 |
| 戴眼镜侧脸女 | 模型输出碎片框（conf 0.18~0.43），未过 0.25 置信度 | 训练标签中该区域三个框严重互相重叠（预标注噪声），模型学成碎片输出 |

### 8.2 人数优先判定逻辑（seat_v6 起生效）

优先级：**准确统计在座人数 > 座位归属的精确性**。

1. **主体强命中**：人框与座位 ROI 重叠率 ≥ `person_iou_threshold`(0.50)；
2. **中心点兜底**：强命中未过、但框中心落在座位 ROI（外扩 `person_center_fallback_margin`=60px）
   内的，也计为该座位有人——解决「椅子被角度遮挡但人可见」的漏检；
   兜底前先做跨座位去重：与任何座位已命中人框重叠 > 0.5 的碎片不重复计数；
3. **边界溢出剔除**：人框在本座位重叠率 < `person_spill_own_ratio`(0.75)、
   且覆盖已有命中的邻座 ROI ≥ `person_spill_neighbor_ratio`(0.20)、
   且与邻座已命中人框实际重叠 ≥ 0.2 时，判定为「ROI 边界切割人框产生的碎片」，剔除；
4. **全图在座人数 total_persons** = 各座位人数之和（座位内去重 + 上述两道去重后），
   看板上传图片识别结果中直接展示。

实测：real_03 在座 6/6 全对；real_02 在座 8/8、13 座三态与基线一致；单座视频时序回归通过。

### 8.3 实体座位（红脚凳 S14）

- 数据集新增 `stool` 类（id=5，data.yaml nc=6）；红脚凳 = 一把无靠背塑料凳，计为一个座位。
- 座位配置 `exists_check: stool`：ROI 内检测不到凳子实体时判 **ABSENT（不在画面）**，
  不计入座位总数、不写观测、不进状态机——「上传图片中没有该凳则不计为座位」。
- YOLO 对 stool 样本（仅 1 例）召回不足，配置 HSV 红色色块兜底：
  ROI 内出现面积 ≥4%、长宽比 0.5~1.6 的高饱和红色实心块即认为凳子存在。
- exists_check 座位不判「有物无人」（凳子无配套桌面，凳边杂物不构成占座信号）。

## 九、座位两级判定与整洁标注（2026-11-06 第二次修订）

### 9.1 座位定义（最终版，全模式统一）

1. **第一级（座位存在性，最大化座位数）**
   - 一把椅子/凳子实体 = 一个座位（标定模式：人工核验的座位表即椅子清单；动态模式：chair/stool 检测去重后每框一座）；
   - 受画面限制未检测到椅子、但该处能检测到人 → 该处也计为一个座位（动态模式「隐式座位」，标签为「人位」）。
   - 防双计：与某椅子落座区接触 ≥15% 但未达归属阈值的人，不生成隐式座位。
2. **第二级（占座状态）**：座位内有人 → 有人；无人但有物品证据 → 有物无人；否则空置；
   `exists_check` 座位画面中无实体 → 不在画面（不计座位）。

### 9.2 整洁标注规则（绘制层，2026-11-06 起生效）

- 座位框 = **紧致证据框**：有人 → 座位内人框并集（裁剪到判定 ROI）；有物无人 → 物品框并集；空置 → 椅子紧致 ROI；不在画面 → 细灰框+小标签。
- **不再叠加全部原始检测框**；仅「未被任何座位吸收」的人框画红框并标注「人(未入座)」。
- 判定用大 ROI（跨昼夜稳健）与显示用紧致框**分离**，解决「矩形 ROI 互相穿插显得框不准」的问题。
- 标签黑描边，任意底色可读。

### 9.3 标签质量纪律（训练数据）

- 同类框 IoU>0.6 视为重复，必须合并（`scripts/clean_labels.py`）；
- 大图近景（real 系列）中面积 <0.0008 的物品框视为噪声删除；
- 俯瞰图过扁人框（俯视合法）保留；
- 新增标注前先跑 `python scripts/clean_labels.py` 做 dry-run 校验。
